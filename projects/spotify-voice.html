Spotify Voice Control

2026 Python · Vosk
GitHub ↗

A voice control utility for Spotify and any app that listens to system media keys. It runs in the Windows tray and uses offline speech recognition, so basic commands work without sending audio to the cloud.

How it works

  • Vosk listens on the default microphone and matches phrases from a local config
  • Commands include next/previous track, play, pause, and open Spotify
  • Optional Spotify Web API support for account login and playback control
