Careerbase

2026 React · FastAPI · PostgreSQL · Playwright
Live site ↗ · GitHub ↗

Careerbase is a job board that pulls software engineering postings directly from company ATS systems — Greenhouse, Lever, Ashby, Gem, and Workday — plus custom scrapers for Google, Apple, and Microsoft.

How it works

  • Frontend is a React SPA with search and filters for title, company, and location
  • Vercel functions proxy ATS APIs; a FastAPI backend stores listings in PostgreSQL
  • Playwright scrapers pull jobs from company career sites, including incremental updates
