Launchframe

2026 Next.js · shadcn/ui
GitHub ↗

Launchframe is an AI-ready Next.js starter for turning any site into a SaaS landing page. npx launchframe scaffolds a project with agent instructions and a /launchframe slash command for Cursor, Claude Code, Copilot, and others.

How it works

  • Point it at a site you like and describe your product
  • The agent inspects the page in the browser and rebuilds the layout in React
  • It then swaps in your name, copy, and branding
